# Blu Snu: Miscellaneous

This document contains miscellaneous information about the Blu Snu project that doesn't fit into the other categories.

## Dependencies

The Blu Snu project relies on a number of open-source libraries and tools. These include:

*   **Kotlin:** The primary programming language for the project.
*   **Jetpack Compose:** The UI toolkit for the project.
*   **Room:** The persistence library for the project.
*   **Ktor:** The HTTP client for the project.
*   ** kotlinx.serialization:** The JSON serialization library for the project.
*   **AzNavRail:** The navigation library for the project.
*   **osmdroid:** The map library for the project.

## Future Plans

The Blu Snu project is under active development. Future plans include:

*   **Adding more attack modules:** The project will be extended to include more attack modules for both Bluetooth Classic and BLE.
*   **Improving the automation core:** The automation core will be enhanced to support more complex attack chains and triggers.
*   **Expanding the vulnerability database:** The vulnerability database will be updated regularly to include the latest known vulnerabilities.
*   **Adding support for more hardware:** The project will be extended to support more external hardware devices for advanced attacks.
*   **Improving the reporting engine:** The reporting engine will be enhanced to provide more detailed and customizable reports.
